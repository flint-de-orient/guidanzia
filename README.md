# Guidenzia — AI Career Counselling

An AI-powered career-guidance platform for Indian students. A student completes a
multi-module assessment plus aptitude/behavioural games, and the system (backed by
Google Gemini) generates a psychometric profile, ranked career matches, and detailed
per-career reports.

## Repository layout

| Folder | Stack | What it is |
|--------|-------|------------|
| `backend/` | Python · Flask | REST API, assessment scoring, AI generation (Gemini), MongoDB storage |
| `frontend/` | Vite · React · TypeScript | Web client |
| `mobile_app/` | Flutter · Dart | Android mobile client (the primary client) |
| `app_frontend_ideas/` | HTML mockups | Stitch design-system reference (not runtime code) |

## Prerequisites

- **Python** 3.8+
- **MongoDB** 4.4+ running locally (or reachable via `MONGO_URI`) — e.g. MongoDB Community Server + Compass
- **Node.js** 16+  (npm)
- **Flutter** 3.x (Dart SDK `^3.12.2`) + Android SDK/`adb`, for the mobile app
- A **Google Gemini API key** — free from <https://aistudio.google.com>

## 1. Configure environment variables (do this first)

Both the backend and the frontend read a **single `.env` file at the project root**
(`career_counselling/.env`). It is **git-ignored** and never committed — you must
create it locally.

```bash
cp .env.example .env
```

Then fill in the values:

| Variable | Used by | Notes |
|----------|---------|-------|
| `GEMINI_API_KEY_1` … `GEMINI_API_KEY_4` | backend | Gemini keys (a fallback pool — at least one is required; add more to raise the quota) |
| `VITE_API_BASE_URL` | frontend | Backend URL, e.g. `http://localhost:8080` |
| `MONGO_URI` | backend | MongoDB connection string (default `mongodb://localhost:27017`; use a credentialed URI in production) |
| `MONGO_DB` | backend | Database name (default `guidenzia`) |
| `GEMINI_MODEL` | backend | *optional* — model id override |
| `GEMINI_MAX_CONCURRENCY` | backend | *optional* — parallel-request cap |

> The **mobile app does NOT use `.env`** — it receives the backend URL at launch via
> `--dart-define` (see section 4).

## 2. Backend (Flask API)

```bash
cd backend
python -m venv venv && source venv/bin/activate   # optional but recommended (Windows: venv\Scripts\activate)
pip install -r requirements.txt
playwright install chromium                        # only needed for PDF report export
python app.py
```

Runs on **http://localhost:8080**. Data is stored in **MongoDB** (database
`guidenzia`) — make sure a MongoDB server is reachable at `MONGO_URI` before
starting (locally: run `mongod` / MongoDB Compass on `localhost:27017`). The
backend ensures its indexes on startup; no seed data is needed.

> **Reset the database:** `python truncate_db.py` empties all collections
> (keeps indexes + validators); `python truncate_db.py --drop` removes the
> whole database.

## 3. Frontend (Vite web app)

```bash
cd frontend
npm install
npm run dev
```

Runs on **http://localhost:5173** and calls the backend at `VITE_API_BASE_URL`.

## 4. Mobile app (Flutter)

```bash
cd mobile_app
flutter pub get
flutter run --dart-define=API_BASE_URL=http://<backend-host>:8080
```

Choosing the right `API_BASE_URL`:

- **Android emulator:** `http://10.0.2.2:8080` (the host machine's loopback).
- **Physical device (USB):** run `adb reverse tcp:8080 tcp:8080`, then use
  `http://localhost:8080`.
- **Same Wi‑Fi:** your machine's LAN IP, e.g. `http://192.168.1.5:8080`.

## Quick start (backend + frontend together)

```bash
./start-dev.sh        # macOS/Linux
start-dev.bat         # Windows
```

## What's intentionally not in the repo

These are generated/secret and are recreated locally — **never commit them**:

- `.env` — your real secrets (create it from `.env.example`)
- MongoDB data lives in your MongoDB server (`guidenzia` database), not in the repo
- `node_modules/`, `mobile_app/build/`, `.dart_tool/`, `__pycache__/` — dependencies &
  build output (regenerated by `npm install` / `flutter pub get` / building)

> ⚠️ This repository is **public**. Keep the real `.env` local. If a key is ever
> committed by accident, rotate the affected Gemini keys immediately.
